# Textures

There are four types of texture. Each is sent from the Texture tab on the [submit page](https://mctitlegenerator.com/submit/).

| Type | What it is |
| --- | --- |
| [Texture](#texture) | Painted over one font's template, so it can give every letter its own detail |
| [Overlay](#overlay) | A see-through layer drawn over whatever texture is picked |
| [Strip](#strip) | Covers the top faces, front and bottom faces of every letter at once, repeating along the line |
| [Tileable](#tileable) | A small seamless pattern repeated across the letters, on any font |

## Texture

A texture is painted over a font's template, `public/fonts/<font>/textures/flat.png`. The template has every character laid out in rows. Each row has the top faces of the characters above them, the fronts in the middle, and the bottom faces below. Paint inside those shapes and leave the rest see-through. Pixels outside the shapes add to the letters, and gaps cut holes in them.

- The texture is the template's size, or a whole number of times bigger, eg 2x or 4x for more detail. It can be up to 4096 pixels on each side.
- Its border colour is the colour of the letters' outline. It is set on the submit page, not painted.
- A variant is listed under another texture, like a different colour of it.
- A texture can be the font's primary, which top and small lines start with, or its secondary, which bottom lines start with, if the font does not have one yet.
- A texture can come with default overlays and face colours, used when someone picks it. A font with layers can have different ones on each layer.

On the submit page, the font is picked for you from the size and shape of the PNG.

## Overlay

An overlay is drawn over whatever texture is picked. It is painted over a font's template like a texture, at the same sizes, and is mostly see-through.

An overlay can have up to 5 colours. Put shading, glows and fades in its transparency instead. People can recolour each of the overlay's colours in the generator.

Some overlays, like outlines, shines and highlights, are generated by the site and have no PNG.

## Strip

A strip holds the top edge of the letters, their front, then the bottom edge. It repeats along the line, so it can be any width. Letters that reach above or below its front repeat its top or bottom row.

A strip belongs either to a strip type shared by several fonts, or to a single font. Download a blank strip from the font editor's Textures tab to paint over.

### Strip types

A strip type is a set of strips any font can use. Its shape is three numbers, all required:

- **Depth:** how many rows each edge takes.
- **Height:** how many rows the front has above the baseline.
- **Baseline:** the rows from the bottom of the strip up to the baseline, including the bottom edge.

Minecraft Ten's strips are 22, 40 and 30, making them 92 rows tall: 22 for the top edge, 40 for the front above the baseline, 8 below it, and 22 for the bottom edge.

Every font uses the `default` type without listing it, so every strip in it has to stretch.

On the submit page you can send a strip to an existing type, to one font, or start a new type and pick the fonts that use it.

### Sizes

A strip is as tall as its rows, eg 92 pixels for Minecraft Ten's. It can also be a multiple of that, bigger or smaller, like 1/2, 2x or 4x. The submit page lists the heights that fit.

Its snap is how many pixels wide each of the strip's own pixels are. Letters that do not touch start their strip on a whole one of these, so the pattern lines up from letter to letter.

A strip can stretch its front between each font's baseline and top. One that does not stretch keeps its own rows and has an anchor for fonts shorter or taller than it: `top` lines up their toplines, `base` their baselines, and `center` their middles, rounded to the nearest whole one of the strip's pixels.

Like a texture, a strip has a border colour, and can have variants.

## Tileable

A tileable is a small pattern repeated across the letters, so its edges have to join up without a seam.

- 8x8, 16x16, 32x32 or 64x64
- No see-through pixels
- A variant is listed under another tileable, like a different colour of it, and is the same size

## Files

### textures.json

Each font has a `textures.json` listing its textures, overlays and its own strips. The PNGs go in its `textures` and `overlays` folders, named after their IDs. IDs are lowercase letters and numbers with underscores, like `oak_planks`.

```json
{
  "textures": {
    "flat": { "authors": ["Ewan Howell"] },
    "cracked": {
      "authors": ["ShrimpSnail", "Ewan Howell", "MrBrose"],
      "density": 3,
      "variants": {
        "cracked_left": { "density": 3 },
        "cracked_old_pixelated": { "name": "Cracked Old (Pixelated)", "authors": ["Yanuar Mohendra", "ShrimpSnail"] }
      }
    },
    "bevelled_gold": { "authors": ["CL697", "ShrimpSnail"], "density": 4, "border": "#3f0f0f" },
    "fired": {
      "authors": ["FloideN"],
      "border": "#021935",
      "overlays": [{ "overlay": "outline_fade_inverted", "blend": "overlay", "opacity": 80 }],
      "edgeOverlays": [{ "overlay": "edge_outline_fade", "blend": "overlay", "opacity": 46 }]
    }
  },
  "overlays": {
    "bevel": { "authors": ["Ewan Howell"], "density": 4, "palette": ["#626262", "#6e6e6e", "#e7e7e7", "#d0d0d0", "#a4a4a4"] }
  },
  "primary": "cracked",
  "secondary": "gradient"
}
```

`primary` and `secondary` are the IDs of the textures top and bottom lines start with.

#### Texture keys

| Key | Default | Does |
| --- | --- | --- |
| `name` | The ID in title case | The name shown in the generator |
| `category` | | The name of the group a texture and its variants are shown as |
| `authors` | | Everyone who made it. A variant without any is credited to its parent |
| `basedOn` | | The ID of the texture it was made from, credited alongside it |
| `density` | `1` | How many times bigger than the template it is |
| `border` | The flat texture's | The outline colour, as `#rrggbb` |
| `overlays`, `edgeOverlays` | | Default overlays on the faces and on the edges |
| `faces`, `inner`, `sides` | | Default colours of the top and bottom faces, inner faces and side faces |
| `variants` | | Variants, keyed by ID. Each one takes its parent's keys and changes what it needs to |

A font with layers can give `overlays`, `edgeOverlays` and the face colours as one list per layer.

Each default overlay has its `overlay` ID, and can set its `blend`, `opacity` (0 to 100) and `colours`.

#### Strip keys

Strips take the texture keys, plus:

| Key | Default | Does |
| --- | --- | --- |
| `type` | | `"strip"` |
| `stretch` | `false` | Stretches the front between each font's baseline and top |
| `anchor` | `"center"` | In a strip type, where a strip that does not stretch sits on a shorter or taller font: `"top"`, `"center"` or `"base"` |
| `snap` | One of the strip's pixels | How many of the font's pixels wide each of the strip's own pixels are |
| `tiling` | `"line"` | `"character"` restarts the strip on each letter |

#### Overlay keys

| Key | Default | Does |
| --- | --- | --- |
| `name` | The ID in title case | The name shown in the generator |
| `authors` | | Everyone who made it |
| `density` | `1` | How many times bigger than the template it is |
| `palette` | `["#ffffff"]` | The overlay's colours, which people can change |
| `default` | | The blend, opacity and colours it starts with |

### Strip type folders

A strip type has a folder in `public/strips`, with its PNGs in `textures` and a `textures.json`:

```json
{
  "depth": 22,
  "baseline": 30,
  "height": 40,
  "textures": {
    "gradient": { "type": "strip", "stretch": true, "authors": ["Ewan Howell"] }
  }
}
```

A font lists the types it uses under `strips` in `fonts.json`, eg `"strips": ["minecraft-ten"]`. `{ "id": "minecraft-ten", "layer": 1 }` puts them on one layer of a font with layers. Every strip in the type then shows in the font's textures.

### tileables.json

Tileables are in `public/tileables`, in a folder per source. Submitted ones go in `community`. Each is listed in `tileables.json`:

```json
{
  "checkerboard": { "authors": ["Ewan Howell"], "path": "patterns" },
  "diagonal_up": { "category": "Diagonal", "authors": ["Ewan Howell"], "path": "patterns", "variants": { "diagonal_down": {} } },
  "twisted_wood": { "authors": ["CCCode"], "path": "dokucraft" }
}
```

| Key | Default | Does |
| --- | --- | --- |
| `name` | The ID in title case | The name shown in the generator |
| `category` | | The name of the group a tileable and its variants are shown as |
| `authors` | `["Mojang"]` | Everyone who made it |
| `path` | `"minecraft"` | The folder its PNG is in |
| `variants` | | Variants, keyed by ID. Each one takes its parent's keys and changes what it needs to |
